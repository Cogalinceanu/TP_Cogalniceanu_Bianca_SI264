LABORATOR PYTHON - FUNCȚII, METODE ȘI IMPORTURI PE WEB

Fișiere:
- part1_imports.py: exercițiile 1-8
- part2_methods.py: exercițiile 9-20
- part3_functions.py: exercițiile 21-34
- part4_modules.py: exercițiile 35-43
- webtools.py: modul reutilizabil pentru exercițiile 44-50
- main.py: programul principal; generează report.csv și report.json

Instalare:
    python -m pip install requests

Opțional pentru bonus:
    python -m pip install beautifulsoup4

Rulare:
    python part1_imports.py
    python part2_methods.py
    python part3_functions.py
    python part4_modules.py
    python main.py https://cybercor.org

Notă:
- Cererile web au timeout.
- Unele exerciții depind de accesul la internet și de răspunsurile curente ale site-ului.
- Raportul final poate include avertizări dacă DNS-ul, site-ul sau certificatul nu sunt accesibile.
- Înlocuiți „Student: Numele vostru” cu numele vostru.
